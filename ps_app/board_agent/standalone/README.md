# GA3B v1.0 minimal standalone board agent

This directory contains the first PS-side smoke-test program for the v1.0
minimal hardware path:

```text
PS DDR -> AXI DMA MM2S -> GA3B PL AXI-Stream task input
GA3B PL AXI-Stream result output -> AXI DMA S2MM -> PS DDR
PS M_AXI_GP0 -> GA3B AXI4-Lite status/control registers
```

## Files

- `ga3b_dma_smoke.c`: standalone/Vitis polling test.
- `ga3b_uart_board_agent.c`: persistent UART command agent.
- `../../common/ga3b_protocol.h`: packet constants, AXI-Lite offsets, helper task builder.

## Expected hardware

Generated by `vivado/scripts/create_v1_min_bd.tcl`:

- `ps7_0`
- `axi_dma_0` in simple mode
- `ga3b_accel_0` (`rtl/top/ga3b_v1_min_accel_top.v`)
- PS HP0 enabled for DMA DDR access
- PS GP0 used for DMA and GA3B AXI-Lite registers

## Test behavior

The smoke program builds one `pure3_rf` task packet:

- `GENE_COUNT=8`
- `POP=32`
- `MAX_GEN=2`
- `STEPS=16`

It starts S2MM first, then MM2S, polls DMA/status, invalidates the result buffer,
and prints `GA3B_DMA_SMOKE_PASS` on success.

The current v1.0 minimal board path intentionally uses the routed pure3 fallback
profile, because the earlier restricted4 RTL exceeded ZYNQ-7020 resources/timing.
The restricted4 RTL remains in `rtl/ga_core/` and `rtl/top/ga3b_heng_era_accel_top.v`
for continued development.

## Persistent UART agent

`ga3b_uart_board_agent.c` stays resident on PS Cortex-A9 and accepts ASCII
commands over the PS UART at 115200-8-N-1. Build it with:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run/build_v1_uart_board_agent.ps1
```

The resulting ELF is:

```text
vitis_workspace/v1_min_standalone/ga3b_uart_board_agent/ga3b_uart_board_agent.elf
```

After loading the v1-min bitstream and this ELF, test from the PC with the
currently assigned CH340 port (the COM number can change):

```powershell
python ps_app/host_backend/ga3b_uart_client.py --port COM13 SELFTEST
```

The terminal response is `GA3B_RSP OK SELFTEST_PASS`. The board currently
implements the resource-fit `pure3` profile, not the restricted4 main target.

The accepted build must also pass the fixed-seed 100-run test:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run/run_v1_uart_board_test.ps1 -Port COM13 -Count 100
```

Protocol, re-entrancy, memory-latency, determinism, and build-provenance rules
are normative in `doc/design_contract.md`.
