## 实板候选验证

通过仍在线的 v1.1 HTTP 服务从 COM13/FPGA 获取多组真实轨迹，再调用 v1.1.1 指标评分器。测试确认：

- `close_pass` 可以与纯 `survival` 选择不同候选；
- 当前候选池中 `braid`/`recurrence` 可能仍只能返回最优近似；
- 因此新增 `profile_match` 判据，未达标时 UI 必须报警，禁止只换目标文案却把背离轨迹称为纠缠或周期。

## 自定义经典 8 字初态

使用常见归一化初态：

```text
r0=( 0.97000436,-0.24308753) v0=(0.466203685,0.43236573)
r1=(-0.97000436, 0.24308753) v1=(0.466203685,0.43236573)
r2=-(r0+r1)               v2=-(v0+v1)
```

在当前 RTL 近似力模型下请求 8192 步：

```text
survived_steps=2231
winding_radians=5.2821
compact_fraction=0.3743
close_pass_count=1
failure=collision_or_escape
```

这套初态适合展示“三星纠缠一段时间”，但不能声称在当前近似模型中达到 8192 步稳态。经典解在真实牛顿引力模型中的性质不能直接移植到分段力近似模型。

## 承载与校验

- HTTP 搜索：`max_gen<=256`、`steps<=65536`、multi-start `<=16`、预计同步负载 `<=30s`；
- 自定义重放：`steps<=131072` 且预计 PC 同步负载 `<=2s`；
- 浏览器在承载估算返回前禁用提交，后端再次独立校验全部范围和碰撞阈值。

## 长窗口与事件高亮回归

- 推荐搜索窗口：`survival/close_pass=4096`，`braid/recurrence=8192`；
- multi-start 同步服务预算：180 秒；
- 完整重放最多 720 个采样帧，动画窗口最多 120 个连续帧；
- 经典 8 字自定义初态的 8192 步测试中，高亮窗口为绝对 step `0..1428`，完整轨迹终点为 `2232`；
- 帧绝对 step 严格递增，完整 `survived_steps` 与 metrics 未被高亮选择修改。
