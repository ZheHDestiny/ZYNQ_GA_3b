# v1.1.1 多目标轨道实验室使用说明

## 更新后启动

代码更新后必须停止旧 Flask 进程并重新启动，浏览器刷新本身不会让旧 Python 进程加载新 API：

```powershell
# 在旧服务终端按 Ctrl+C
cd F:\ZYNQ\ZYNQ_GA_3b
.\scripts\run\run_v1_web_demo.ps1 -Port COM13
```

本次更新不修改 bitstream、ELF 或 `BOOT.BIN`，因此无需重写 SD 卡。

## 四套目标

1. **长时生存**：只要求有限窗口内不碰撞、不逃逸。
2. **安全擦掠**：在存活前提下奖励多次具有碰撞裕量的近心点事件。
3. **三星纠缠**：奖励绕质心转角、天体角序交换和紧凑驻留，惩罚径向漂移。
4. **近周期回归**：允许等质量天体交换标签，比较末态构型与初态的最小回归误差。

除“长时生存”外，当前实现是“多次 FPGA 生存搜索 + PC 物理指标重排”，不是四套原生 RTL fitness。页面会显示硬件候选数，并在指标不达标时发出警告。

## 自定义初态

切换至“自定义初态”后输入太阳 α、β 的位置和速度；太阳 γ 自动满足质心和总动量为零。前后端都会检查：

- `x/y` 在 `[-2,2]`；
- `vx/vy` 在 `[-1,1]`；
- 初始 L1 两体距离不小于 0.125；
- 重放步数不超过 131072；
- 预计同步 CPU 时间不超过 2 秒。

默认表单是经典牛顿三体 8 字解的常见归一化初态。由于当前 PL 使用分段力近似，它只适合观察“纠缠一段时间”的视觉效果，不能把最终逃逸解释为经典解本身不稳定。

## 播放控制

轨迹区域支持暂停、时间轴拖动和 0.25×–8× 播放速度。推荐窗口为：长时生存/安全擦掠 4096 步，三星纠缠/近周期回归 8192 步。服务同步预算已提高到 180 秒。

动画默认使用最多 120 个连续帧的事件高亮窗口，避免后期背离把早期近掠压缩到不可见。右上角会显示 `HIGHLIGHT start-end / FULL start-end`。高亮只改变镜头展示范围，完整 fitness、存活步数和目标判据不变。
