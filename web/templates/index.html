GA3B 网页版 README

01

确认链路

右上角显示 BOARD ONLINE 才能运行 FPGA 搜索。若显示 LINK DOWN，请确认 SD 冷启动、USB UART、COM 端口和 PC 后端；关闭所有会占用串口的终端。

02

选择目标

长时生存允许彼此远离；安全擦掠奖励近距离掠过；三星纠缠奖励绕转、换位和紧凑驻留；近周期回归奖励末态构型返回。后三项会搜索多组 FPGA 候选再由 PC 重排。

03

等待承载估算

参数改变后，提交按钮会暂时锁定。只有预计时间不超过服务预算时才允许上传。较长窗口更容易看到完整事件，但需要等待更多时间。

04

理解高亮窗口

动画默认展示完整计算结果中最富有近掠或纠缠特征的一段连续物理轨迹。右下角会显示原始 step 范围；存活数、fitness 和目标判据始终来自完整轨迹，不会因展示裁剪而改变。

05

检查结果是否吻合

如果状态显示“仅为当前候选中的最优近似”，表示候选没有达到所选物理判据。不要仅凭动画把它解释为周期解或稳定纠缠。

06

自定义初态

可输入太阳 α、β 的位置和速度，太阳 γ 自动满足质心与总动量约束。该模式是 PC 上的 RTL 同规则重放，不是 FPGA 搜索。默认经典 8 字初态可用于观察一段明显纠缠。

07

播放和遥测

使用时间轴、暂停和 0.25×–8× 速度检查近心点过程；点击顶部“性能遥测”跳转到性能探针，“系统信息”查看当前板卡、profile 和服务限制。

08

十进制参数语义

x/y 是质心坐标系中的归一化位置，vx/vy 是归一化速度。页面显示的是 Q16.16 解码值；旁边的 Q16 整数等于物理值乘 65536。变异率和交叉率输入 0–65535，概率等于输入值除以 65536。Seed 使用有符号十进制显示，传入 FPGA 时按同一 32 位二进制补码解释。

09

模范解与本地保存

“选择模范解”会用固定 seed 再次启动真实 FPGA 搜索。每次搜索和自定义重放均自动保存到本地 SQLite。长时生存与近周期回归都是有限窗口标签，不代表数学上的无限稳定或严格周期证明。

只有静态前端怎么办？

若页面能打开但所有 API 都失败，说明 Flask 后端没有运行。请在项目根目录执行 .\scripts\run\run_v1_web_demo.ps1 -Port COM13。单独双击 HTML 文件不能访问 FPGA。
